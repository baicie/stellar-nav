# 缺德导航 v0.0.2

本版本调整 Android 发布包装方式：可直接安装的侧载包按 ABI 拆分，避免一个通用 APK 同时携带多套原生库。应用功能与数据性质边界保持不变。

## Android 下载

- `stellar-nav-android-arm64-v8a.apk`：适用于绝大多数现代 Android 真机；
- `stellar-nav-android-armeabi-v7a.apk`：适用于仍使用 32 位 ARM 的旧设备；
- `stellar-nav-android-x86_64.apk`：适用于 x86_64 模拟器或设备；
- `stellar-nav-android.aab`：Android App Bundle，用于应用商店提交，不可直接安装；
- `SHA256SUMS.txt`：三个 APK 与 AAB 的 SHA-256 校验值。

每个 APK 只包含文件名所示 ABI 的原生库。本版本不提供通用 APK、32 位 x86 APK 或 iOS 包。所有 Android 包沿用 v0.0.1 的 release keystore 签名，并由 GitHub Actions 生成构建来源证明。

签名证书 SHA-256 指纹：`D4:CC:2E:B0:73:4E:E8:38:FF:1E:0A:B3:69:EF:2A:64:B8:FA:89:C2:C3:AD:93:47:9F:47:86:9A:A6:D5:DA:18`。

## 安装与校验

先在设备系统信息或安装工具中确认 ABI，再下载对应 APK。下载 `SHA256SUMS.txt` 与全部四个二进制产物到同一目录后，可校验文件完整性：

```bash
sha256sum --check SHA256SUMS.txt
```

在 Android 设备按系统提示允许本次来源安装并完成安装。若设备上已有使用不同签名的开发版，请先卸载开发版再安装；使用 v0.0.1 正式签名包的设备可直接升级。

## 数据性质说明

界面中的天体对象来自版本化演示星表；距离标记为观测或推导数据，路线、耗时、燃料和风险属于模拟结果，程序化星野和玩法设定属于虚构内容。本应用只用于图一乐，不可用于真实航天导航。

## 回滚

已发布的标签和资产不会移动或覆盖。若 v0.0.2 出现阻断问题，将停止分发本版本，在 `main` 回退问题改动，并以更高的版本号和 `versionCode` 发布使用同一证书签名的修复包。Android 不允许较低 `versionCode` 的 v0.0.1 直接覆盖 v0.0.2；必须回到旧版的用户需要先卸载当前版本，可能同时清除本地应用数据。
