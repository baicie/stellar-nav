# 缺德导航 v0.0.1

首个可安装的 Android 版本。它提供星图探索、演示航线对比、目的地与图层切换，以及基于 Skia/Reanimated 的连续航行动效。

## Android 下载

- `stellar-nav-android-v0.0.1.apk`：通用安装包，可直接安装到 Android 真机或模拟器；
- `stellar-nav-android-v0.0.1.aab`：Android App Bundle，用于后续提交 Google Play，不可直接安装；
- `SHA256SUMS.txt`：两个包的 SHA-256 校验值。

两个 Android 包使用同一份持久 release keystore 签名，并由 GitHub Actions 生成构建来源证明。当前版本暂不提供 iOS 包。

签名证书 SHA-256 指纹：`D4:CC:2E:B0:73:4E:E8:38:FF:1E:0A:B3:69:EF:2A:64:B8:FA:89:C2:C3:AD:93:47:9F:47:86:9A:A6:D5:DA:18`。

## 数据性质说明

界面中的天体对象来自版本化演示星表；距离标记为观测或推导数据，路线、耗时、燃料和风险属于模拟结果，程序化星野和玩法设定属于虚构内容。本应用只用于图一乐，不可用于真实航天导航。

## 安装

在 Android 设备下载 APK 后，按系统提示允许本次来源安装并完成安装。若设备上已有使用不同签名的开发版，请先卸载开发版再安装本版本。

## 回滚

这是首个公开版本，没有可回滚的更早正式包。若出现阻断问题，将撤下 Release 资产并发布递增版本号的新签名包；不会移动或覆盖已经发布的版本标签。
