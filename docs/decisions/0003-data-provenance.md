# ADR-0003: 强制保留数据性质和来源上下文

- 状态：Accepted
- 日期：2026-08-05

## 背景

产品使用真实天文对象名称，但路线、风险和飞船能力是娱乐模拟。如果没有明确标签，用户会把演示数字误认为航天或观测事实。

## 决策

所有对用户有意义的数据都带有 `Provenance`，并标记为 `observed`、`derived`、`simulated` 或 `fictional`。MVP 使用版本化的小型演示星表；导航模型采用确定性公式，界面展示中文性质标签。接入外部数据前必须记录来源、版本、许可和计算模型。

## 结果

娱乐表达和科学数据边界可同时存在，测试可以验证标签不会丢失。代价是数据类型和文案略显冗长，但这是可信度和后续数据管线的必要成本。
